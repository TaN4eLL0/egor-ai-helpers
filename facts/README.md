# facts/

Кэш проверенных фактов. Каждый файл — один факт, проверенный по официальному
источнику, с датой проверки. Нужен, чтобы не ходить читать одну и ту же
документацию заново в каждой сессии.

Путь к этой директории подставляется в `~/.claude/CLAUDE.md` installer'ом через
`{{REPO_ROOT}}`, поэтому кэш общий для всех проектов — в отличие от файловой
памяти Claude Code, которая привязана к рабочей директории.

## Формат

```markdown
---
topic: gradle-build-cache
verified: 2026-09-01
source: https://docs.gradle.org/current/userguide/build_cache.html
volatility: stable
---

Текст факта. Формулировки — как в источнике, без пересказа своими словами.
```

| Поле | Что |
|---|---|
| `topic` | kebab-case, совпадает с именем файла |
| `verified` | `YYYY-MM-DD`, когда источник реально открывался |
| `source` | URL страницы или путь к файлу, который проверялся |
| `volatility` | `stable` или `volatile` |

## volatility

`stable` — семантика, поведение по умолчанию, архитектурные принципы. Такое не
меняется годами, поэтому действует срок 4 месяца: старше — перепроверить и
обновить `verified`.

`volatile` — номера версий, имена флагов и API, лимиты, цены, deprecations,
model ID, структура URL. Перепроверяется **всегда**, независимо от даты: такое
может смениться за неделю, и дата тут ничего не гарантирует.
